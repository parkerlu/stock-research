## 风险声明

1. **累计回报口径**：sum-of-trade-pct（不复利、不计 portfolio 占比）。便于策略间对比，不直接等同于实盘账户增长。
2. **样本偏差**：1004 只股票均为 2019-01 后已上市存活的（生存者偏差）。
3. **手续费**：未计入（双边 0.05% 估算后实测仍宽裕通过 6% 平均门槛）。
4. **流动性**：未对小盘 / 停牌做特殊处理；实盘前需做加固。
