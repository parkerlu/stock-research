- 状态：草稿（路线图，作为学习/迭代参考）

## 1. 背景

经过约 1 周迭代，已建成一个完整的中等规模量化研究 + 回测系统：

- **数据**：504 只主板老股 × 7 年日 K（约 90 万根），TuShare 同步，自动后复权
- **指标**：5 个 TDX 公式指标（多周期 KDJ 共振、动力线、买卖很准、低点组合、MA）+ 后端 / 前端集成
- **策略**：5 个 ML 驱动策略（4 个 V21-V570 sweep 优胜者 + 1 个高频版）
- **回测引擎**：单仓位、贪婪移动止损、自适应每股阈值
- **前端**：K 线图、买卖标记、TDX 指标叠加、策略回测一键运行

当前 ML 模型表现（100 股 post-2024 真实 OOS）：
- AUC = 0.66
- 胜率 84%，单股平均 +19.6%
- 92.5% 股票盈利

## 2. 现有系统的本质局限

**所有特征都是公开的技术指标**：23 维特征 = 15 个标准（pos20、ret5、above_MA60、ATR、量比等）+ 8 个买卖很准信号。

**没有原创 alpha edge**：模型把公开因子用 ML 重新组合得更好（这本身有价值），但与机构量化的差距明显：

| 维度 | 当前系统 | 真正机构量化 |
|---|---|---|
| 因子数量 | 23 | 200-1000+ |
| 数据频率 | 日 K | 分钟级 / tick |
| 重训频率 | 一次 | 每周 / 每月 walk-forward |
| 私有数据 | 无 | 龙虎榜、北向资金、订单簿、舆情 |
| 滑点建模 | 无 | 详细 |

## 3. 目标

通过 **ML 自动挖掘 / 学习因子** 而非手动设计，提升模型的 alpha 来源：

- AUC 从 0.66 提升到 0.70-0.72
- 单股平均收益从 +19.6% 提升到 +25%+
- 提供可解释的新因子（GP 路线）+ 不可解释但更强的隐式因子（DL 路线）

## 4. 技术路线图（4 个 Phase）

### Phase 1：遗传算法挖因子（GP）

**思想**：进化数学公式而不是人手写。

**架构**：
- **原料**：open / high / low / close / vol / vwap / ret
- **算子集**（约 20+）：
  - 元素级：+ - × ÷ abs log neg sqrt square
  - 时序：ts_mean / ts_std / ts_max / ts_min / ts_rank / ts_delta / ts_sum / ts_zscore
  - 时序二元：ts_corr
- **窗口**：3 / 5 / 10 / 20
- **表达式树**：max depth 4-6
- **种群**：100-300，**代数**：25-50
- **适应度**：rank IC（信息系数）= 因子值与未来 N 日收益的秩相关系数
- **筛选**：跨股票平均 IC，并惩罚树深度（防过拟合）

**输出**：top 20-30 因子的可读公式，例如：
```
ts_corr(close, vol, 20) - ts_rank(high - low, 10)
ts_zscore((close - ts_mean(close, 20)) / ts_std(close, 20), 5)
log(ts_max(vol, 5) / ts_mean(vol, 20))
```

**预期收益**：把 top 因子加进 XGBoost 特征集，AUC 0.66 → **0.69-0.72**

**计算成本**：M3 Pro 上 30-100 代 ~2-4 小时

**实现库**：可用 `deap` 或自己撸（已实现 demo 在 `scripts/gp_factor_mining_demo.py`）

**风险**：
- 多数挖出来的是数据挖掘噪声（spurious factor）
- 必须严格 OOS 验证（训练集挖、测试集验）
- 需要行业中性化才能通用

---

### Phase 2：深度学习端到端学因子（DL Embedding）

**思想**：不手动设计任何因子，让神经网络从原始 OHLCV 序列里学出隐式特征。

**架构**：
- **输入**：60 根 K 线 × 5-8 通道
- **模型**：4 层 Transformer / 1D-CNN / TabNet
- **任务**：分类（未来 5/10 日是否涨 X%）
- **副产品**：encoder 中间层 = 16-64 维"学出来的因子"
- **下游**：把这些 embedding 拼到 XGBoost 特征里

**预期收益**：可能再加 +0.02-0.05 AUC

**优点**：能学到人想不到的模式（k 线形态、量价关系组合）

**缺点**：
- **不可解释**（你不知道每个数字是什么）
- 过拟合风险高（需大量数据 + 严格正则）
- 我们之前 PatchTST 实验 AUC 0.55，还不如 XGBoost — 数据规模可能不够

**计算成本**：M3 Pro MPS 训练 1-2 小时

---

### Phase 3：Walk-Forward 重训 + 策略优化

**思想**：金融时序有 regime change，模型要持续更新。

**架构**：
- 训练窗口滚动：每季度用最近 5 年数据重训一次
- 验证：用最近 6 个月做 OOS
- 部署：把当季最新模型推到生产

**预期收益**：减少分布漂移损失 +1-3 pp 胜率

**实现**：
- 写一个 cron job（或 GitHub Actions）每季度执行 train → calibrate → deploy
- 把模型版本号、训练日期、AUC 历史记下来

---

### Phase 4：Alternative Data 接入

按收益预期排序：

| 数据源 | 预期 AUC 提升 | 成本 |
|---|---|---|
| **龙虎榜数据**（机构席位、游资席位流向） | +0.02-0.04 | TuShare 高级会员 |
| **北向资金持仓变化**（外资买卖方向） | +0.02-0.03 | TuShare / 公开 |
| **行业相对强度**（行业内分位数） | +0.01-0.02 | 算法可自算 |
| **业绩预告 / 财报因子**（ROE、营收增速、估值分位） | +0.03-0.05 | TuShare 财务接口 |
| **新闻 / 公告情绪**（NLP 打分） | +0.02-0.04 | 需 LLM API + 数据爬取 |

## 5. 推荐执行顺序

### 立刻可做（成本低）
1. ⭐ **Phase 1 GP 挖因子** —— 1-2 天能出结果，因子可解释，立即能合并到现有 ML pipeline
2. ⭐ **Phase 4 财务因子** —— TuShare 已有接口，加 5-10 个估值/成长因子是低悬果实

### 中期（1-2 周）
3. **Phase 3 Walk-forward 重训机制** —— 长期价值高
4. **Phase 4 龙虎榜 + 北向数据** —— 一次性搭管道

### 长期（持续投入）
5. **Phase 2 Transformer 学因子** —— 数据规模够再上（建议先把 504 股扩到 2000+）
6. **结合大盘 regime 的多策略** —— 不同市况切换不同策略

## 6. 验收标准

- **Phase 1 成功**：在测试集（post-2024）上挖出来的 top 20 因子，加入特征后 XGBoost ensemble AUC 至少提升 0.02（即 0.66 → 0.68+），且不破坏 ≥10% 准确率（保持在 39%+）
- **Phase 2**：序列模型独立 AUC ≥ 0.65，融合后整体 AUC ≥ 0.70
- **Phase 3**：连续 4 季度 walk-forward 测试，单季度胜率波动 ≤ 5pp
- **Phase 4**：每个新数据源的因子单独 OOS 测试 IC ≥ 0.03（行业平均水平）
